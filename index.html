Политика конфиденциальности

TaskTracker · Последнее обновление: 15 мая 2026 г.

Настоящая политика конфиденциальности описывает, как приложение TaskTracker обрабатывает информацию пользователей.

1. Сбор данных

TaskTracker не собирает и не передаёт третьим лицам никакие персональные данные без вашего ведома. Приложение работает следующим образом:

  • Задачи, проекты и настройки хранятся локально на вашем устройстве.
  • При использовании функции синхронизации данные передаются на защищённые серверы Supabase исключительно для обеспечения работы этой функции.
  • Мы не продаём и не передаём ваши данные рекламодателям или другим третьим сторонам.

2. Аутентификация

Для входа в приложение используется электронная почта и пароль. Данные аутентификации обрабатываются сервисом Supabase в соответствии с их политикой конфиденциальности. Пароли хранятся в зашифрованном виде и недоступны разработчику приложения.

3. Локальное хранение

Все данные приложения (задачи, проекты, метки) хранятся локально на устройстве с использованием защищённого хранилища. При удалении приложения все локальные данные удаляются вместе с ним.

4. Сторонние сервисы

Приложение использует следующие сторонние сервисы:

  • Supabase — облачная база данных и аутентификация (supabase.com)

Использование этих сервисов регулируется их собственными политиками конфиденциальности.

5. Дети

Приложение не предназначено для детей до 4 лет и не собирает сознательно данные от детей этого возраста.

6. Изменения политики

Мы оставляем за собой право обновлять настоящую политику конфиденциальности. Об изменениях будет сообщено через обновление приложения. Продолжение использования приложения после изменений означает согласие с новой редакцией.

7. Контакт

Если у вас есть вопросы по поводу конфиденциальности, свяжитесь с нами по адресу: support@tasktracker.app
