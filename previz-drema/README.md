# ДРЕМА: пилот превиза, сцены 1-3

Тест пайплайна «сценарий → разбор → ансамбль персонажей и локации → 3D с ригом → Three.js-превиз с камерами». Всё собрано через Claude и Higgsfield MCP, без Unreal Engine.

## Что получилось

| Этап | Инструмент | Результат |
|---|---|---|
| Разбор сценария | Claude | `data/breakdown.json`: 6 персонажей, 3 локации, 12 позиций реквизита, звук |
| Концепты персонажей | Higgsfield `nano_banana_pro` | 6 листов в полный рост в A-позе |
| Концепты локаций | Higgsfield `nano_banana_pro` | дом снаружи, гостиная, кухня |
| 3D + риг | Higgsfield `image_to_3d` (Meshy): текстура, авториг, A-pose | 6 GLB со скелетом (Hips/Spine/Arm/ForeArm/UpLeg/Leg/Head) |
| Локации в 3D | Claude, процедурный блокаут на Three.js | сруб в лесу, гостиная с гробом и свечами, кухня под лампами дневного света |
| Позы | Claude, повороты костей в коде | стоит / сидит / рисует / показывает / лежит в гробу |
| Камеры | `app/shots.js` | 14 шотов: Super 35, реальные фокусные 18-85 мм, наезды, кадр 2.39:1 |
| Рендер | Playwright + Chromium (песочница Higgsfield) | раскадровка всех шотов |

## Замеры

| Метрика | Значение |
|---|---|
| Время от получения сценария до финальных кадров | **~20 мин** (06:18 → 06:39 UTC) |
| из них генерация 9 картинок | ~1.5 мин |
| из них 6 моделей 3D с ригом (параллельно) | ~5 мин |
| Кредиты Higgsfield | **228** (2146.16 → 1918.16): картинки ~18, 3D 6 × 35 = 210 |
| Токены Claude (по счётчику бюджета сессии) | ~190 тыс. |
| Итерации правок камер и поз | 2 (+1 отладочный рендер сверху) |
| Объём кода | ~32 КБ JS/HTML |

Экстраполяция грубая. Ассеты (персонажи, локации) переиспользуются между сценами, поэтому дальше дешевле: новые сцены в тех же локациях стоят только токенов на шот-лист и правки, без кредитов.

## Озвучка реплик

14 реплик сцен 1-3 озвучены моделью Higgsfield `seed_audio` по 0.4 кредита за реплику:
- **Мать** - пресет «Elena», для молитвы и тихих реплик скорость речи понижена;
- **Ерёма** - детский голос, полученный по концепт-арту персонажа (image reference). Чтобы голос не плавал между репликами, все остальные реплики Ерёмы клонированы с первой записи (audio reference).

Каждая реплика проверена распознаванием речи (faster-whisper): язык русский, текст совпадает.
Таймкоды лежат в `app/shots.js` (`lines`: `at` - секунда от начала шота, `len` - длина, `audio` - ключ файла).
В браузере аниматик проигрывает реплики синхронно с камерой и показывает субтитры.
Хронометраж сцен 1-3 с репликами: ~80 с.

## Как запустить

```bash
cd previz-drema/app
python3 -m http.server 8000
# открыть http://localhost:8000 - список шотов справа, кнопка «Аниматик» проигрывает всё подряд
node render.mjs http://localhost:8000/index.html renders   # PNG всех шотов (нужен playwright)
```

GLB-модели грузятся с CDN Higgsfield (`app/assets.js`).

## Известные ограничения

- Позы статичные. Анимации внутри шота нет, движется только камера. Следующий шаг: клипы из библиотеки Higgsfield `animation_actions` (678 движений) или ключи на кости.
- Позы собраны поворотами костей «на глаз». Рука Деда в 2E чуть приподнята, кисти Матери не касаются руки покойника (2C).
- Локации собраны из примитивов, без текстур. Концепт-арты лежат рядом как референс.
- Сеть облачного контейнера Claude не пускает к CDN Higgsfield, поэтому рендер шёл в песочнице Higgsfield. Локально у пользователя всё работает напрямую.
